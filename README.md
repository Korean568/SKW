# Second Korean Wars (제2차 한국전쟁)

브라우저에서 돌아가는 1인칭 3D 싱글플레이 게임입니다. (PC 전용 · 크롬/엣지 권장)

▶ **플레이: https://korean568.github.io/SKW/**

## 조작법
| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| Shift | 달리기 |
| 마우스 | 시점 / 조준 |
| 좌클릭 | 사격 |
| 우클릭 | 정조준 |
| R | 재장전 |
| F | 방탄판 교체 (방탄판이 깨졌을 때 — 깨진 상태에서는 몸 2발 / 머리 1발에 사망) |
| Space / 클릭 | 대화 넘기기 |
| Tab | 대화 건너뛰기 |
| Esc | 일시정지 |
| F2 | 좌표 표시 (스토리 만들 때 위치 확인용) |

## 스토리 / 대사 고치기
`js/story.js` 파일 하나만 고치면 됩니다. 파일 맨 위에 쓸 수 있는 명령이 전부 설명되어 있어요.
- 캐릭터 이름·계급: `CHARACTERS`
- 챕터(스토리): `CHAPTERS` — 위에서 아래로 순서대로 실행됩니다.

## 내 컴퓨터에서 실행하기
`.glb` 파일을 불러와야 해서 파일을 더블클릭하면 안 되고, 간단한 서버가 필요합니다.
```
python tools/serve.py
```
그다음 브라우저에서 http://localhost:8123 접속.
주소 뒤에 `?debug&ch=2` 를 붙이면 2번째 챕터부터 바로 시작합니다 (디버그 모드, N = 단계 건너뛰기).

## 폴더
- `character/` 캐릭터 (.glb) · `map/` 맵 · `object/` 소품
- `js/` 게임 코드 (`story.js` 만 고치면 스토리 변경)
- `css/` 화면 디자인
