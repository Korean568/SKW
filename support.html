오류를 알려 주실 때는 다음을 함께 적어 주시면 빨리 해결할 수 있습니다:

  • 기기 이름과 iOS / iPadOS 버전 (설정 › 일반 › 정보)
  • 게임 버전 (게임의 설정 › 버전, 예: 0.16)
  • 무엇을 하다가 어떤 일이 생겼는지, 가능하면 화면 캡처

자주 묻는 것

  • 필요한 기기: iOS / iPadOS 26 이상. 게임 화면은 WebGPU 로 그립니다.
  • "WebGPU 를 사용할 수 없습니다" 화면이 나와요: iOS 를 최신으로 업데이트하고(설정 › 일반 › 소프트웨어 업데이트), 차단 모드(Lockdown Mode)를 켰다면 이 앱을 예외로 둔 뒤(설정 › 개인정보 보호 및 보안 › 차단 모드 › 웹 브라우징 구성) 다시 시작해 주세요.
  • 게임 업데이트: 인터넷에 연결되어 있으면 앱이 같은 게임의 새 버전을 스스로 받아 확인(SHA-256)한 뒤 적용합니다. 게임의 설정 › 버전에서 직접 확인할 수도 있습니다.
  • 진행 · 설정 저장: 이 기기의 앱 저장 공간에만 저장됩니다 (앱을 지우면 함께 지워짐).
  • 개인정보: 어떤 정보도 수집하지 않습니다 — 개인정보처리방침

When you report a problem, please include:

  • your device and its iOS / iPadOS version (Settings › General › About)
  • the game version (in the game: Settings › Version, for example 0.16)
  • what you were doing and what happened, with a screenshot if possible

Frequently asked

  • Requirements: iOS / iPadOS 26 or later. The game is drawn with WebGPU.
  • I see "WebGPU is not available": update iOS (Settings › General › Software Update). If Lockdown Mode is on, exclude this app (Settings › Privacy & Security › Lockdown Mode › Configure Web Browsing), then restart the game.
  • Game updates: when online, the app downloads new versions of the same game by itself, checks them (SHA-256) and applies them. You can also check in the game under Settings › Version.
  • Progress and settings: stored only in the app's storage on this device (deleting the app deletes them).
  • Privacy: nothing is collected — Privacy Policy
