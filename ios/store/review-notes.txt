App Review notes (App Store Connect > App Review Information > Notes) - English for the reviewer

Second Korean Wars is a first-person story game. The whole game (HTML + JavaScript, rendered with WebGPU) is bundled inside the app and runs fully offline in a WKWebView; no login, no accounts, no purchases, no ads, no tracking, no data collection.

How to play: on the title screen choose a story (start with Story 1). Drag the left side of the screen to move and the right side to look; the buttons on the right fire, aim and pick up. Settings (graphics, sound, subtitles, language Korean/English) are on the title screen.

Requirements: iOS / iPadOS 26 or later (WebGPU). On a device without WebGPU the game shows its own explanation screen instead of crashing.

Content updates: when online, the app reads a small public JSON file (latest.json) from the game's own public GitHub repository (a fixed first-party address) and may download an updated version of the same game's content (HTML/JavaScript). A download is used only after its SHA-256 matches the value in latest.json. This is interpreted code run only by WebKit (WKWebView), never native code, as allowed by section 3.3.1(B) "Executable Code" of the Apple Developer Program License Agreement: it contains only new versions of this same game, does not change the app's primary purpose, does not bypass signing, the sandbox or other security features, and does not offer other apps or games. Nothing about the user is sent. If you prefer, we can ship a build with content updates switched off (Info.plist key SKWAutoUpdate = NO) so that every change comes through App Store updates.

Privacy policy: in the app under Settings > Privacy > Privacy Policy (opens https://korean568.github.io/SKW/privacy.html). Support: https://korean568.github.io/SKW/support.html

Content: the story is set in a fictional war on the Korean peninsula and is told from both sides - the player also plays a North Korean soldier. It contains gun combat, deaths and one execution scene; swearing is censored. All characters and events are fictional.
